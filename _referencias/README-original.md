## 🚀 Como Publicar Online

### Opção 1: GitHub Pages (RECOMENDADO)

1. Acesse [github.com](https://github.com)
2. Crie uma nova conta ou faça login
3. Crie um novo repositório chamado `seu-usuario.github.io`
4. Faça upload de:
   - `index.html`
   - Pasta `img/` completa
5. Seu site estará em: `https://seu-usuario.github.io`

**Passo a passo com Git:**
```bash
# Clonar seu repositório
git clone https://github.com/seu-usuario/seu-usuario.github.io

# Entrar na pasta
cd seu-usuario.github.io

# Copiar arquivos
cp index.html .
cp -r img/ .

# Fazer commit
git add .
git commit -m "Portfólio Marcos Roberto Herculano"

# Fazer push
git push origin main
```

### Opção 2: Vercel (Muito Fácil)

1. Acesse [vercel.com](https://vercel.com)
2. Faça login com GitHub
3. Clique em "New Project"
4. Selecione seu repositório
5. Deploy automático! ✅

### Opção 3: Netlify (Drag & Drop)

1. Acesse [netlify.com](https://netlify.com)
2. Arraste a pasta do projeto para a área indicada
3. Site online em segundos! ✅

### Opção 4: Hosting Tradicional (Hostinger, etc)

1. Contrate um plano de hosting
2. Acesse o painel de controle
3. Use FTP ou File Manager
4. Faça upload de:
   - `index.html`
   - Pasta `img/` completa
5. Acesse seu domínio

## 🔧 Configuração do Formulário

O formulário está configurado para enviar emails através do **FormSubmit**.

**Como funciona:**
1. Usuário preenche o formulário
2. Clica em "Enviar"
3. Email é recebido em `contato@hrcln.dev`
4. Usuário é redirecionado para uma página de sucesso

Se quiser receber em outro email, altere:

## 📈 Adicionar Google Analytics

Para ver quanto tráfego seu site recebe:

1. Acesse [analytics.google.com](https://analytics.google.com)
2. Crie uma conta
3. Pegue seu ID de medição (começa com `G-`)
4. Adicione antes de `</head>`:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-SEU_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-SEU_ID');
</script>
```

## 🐛 Problemas Comuns

### "As imagens não aparecem"
- Certifique-se que a pasta `img/` está na mesma pasta do `index.html`
- Verifique se os nomes dos arquivos estão corretos
- Recarregue a página (Ctrl+R ou Cmd+R)

### "Menu mobile não funciona"
- JavaScript está ativado?
- Tente em outro navegador
- Limpe o cache (Ctrl+Shift+Del)

### "Formulário não envia"
- Verifique sua conexão com internet
- Verifique o email cadastrado em `action=`
- Procure pela pasta "Spam" no email

### "Cores estranhas"
- Limpe o cache do navegador
- Tente modo incógnito (Ctrl+Shift+N)
- Tente em outro navegador

### "Site quebrado após publicar"
- Verifique se pasta `img/` foi enviada
- Verifique se `index.html` está na raiz
- Recarregue várias vezes (pode estar em cache)
